# 🛡️ Baldur’s Gate 3 – Patch 8 review (15 April 2025)

Patch 8, the major update released on 15 April 2025, brought extensive additions and improvements to Baldur’s Gate 3. Cross-platform play, modding tools, twelve new subclasses and photo mode were among the exciting features introduced to players.

---

## ✨ Highlights

### 🎭 Twelve new subclasses

New subclasses for every class expand the possibilities for role-playing:

| Class | Subclass |
|---|---|
| Barbarian | Path of the Giant |
| Bard | College of Glamour |
| Cleric | Death Domain |
| Druid | Circle of Stars |
| Fighter | Arcane Archer |
| Monk | Way of the Drunken Master |
| Paladin | Oath of the Crown |
| Ranger | Swarmkeeper |
| Rogue | Swashbuckler |
| Sorcerer | Shadow Magic |
| Warlock | Hexblade |
| Wizard | Bladesinging |

---

### 📸 Photo mode

The new **Photo Mode** lets players take creative screenshots, with:
- Extensive camera controls
- Lens settings
- Pose filters
- Stickers and frame options

### 🔗 Cross-platform support

Players on **PC, Mac, PS5 and Xbox Series X/S** can now play together in the same session, even on different devices.

### 🛠️ Modding tools

Larian Studios provides official modding tools. They allow players to customise elements of the game, including maps, quests and dialogue, and install community mods.

---

## 🐞 Bug fixes and performance improvements

Key fixes in Patch 8 include:
- UI improvements and inventory performance optimisation
- Resolved dialogue conflicts
- Visual bug fixes
- Improved console stability

---

## 🎉 Larian’s announcement

Larian described this as the final major content update for Baldur’s Gate 3, with support continuing through smaller patches and fixes.
